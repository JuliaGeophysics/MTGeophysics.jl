Forward modelling

Exact 1D layered-earth responses and a 2D TE/TM finite-difference solver with topography and lakes. 3D runs through ModEM.

Deterministic inversion

Gauss–Newton and NLCG in 1D and 2D, set up from a handful of small text files.

VFSA inversion

Very fast simulated annealing in 1D, 2D and 3D. Several chains give an ensemble of models and an estimate of uncertainty.

Data and meshes

Read and rotate ModEM data files, and build 2D and 3D meshes with topography and water from a data file.

Interactive 3D viewers

Depth slices, cross-sections, phase tensor maps and model editors, with shapefile overlays and GIS export.

What is MTGeophysics.jl? ​

MTGeophysics.jl is a Julia package for magnetotelluric (MT) research and applications. It gives you the building blocks of an MT workflow (reading data, building meshes, forward modelling, inversion and plotting) so that you can test new ideas without rebuilding the basic tools first.

The package reads and writes the same data and model files as ModEM, so you can move models and data back and forth between the two. It is part of the JuliaGeophysics ecosystem.

Install ​

julia
pkg> add MTGeophysics

Then see Getting Started to run your first forward model and inversion.
