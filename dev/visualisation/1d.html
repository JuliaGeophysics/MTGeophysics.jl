1D plots ​

The 1D plots show resistivity against depth as steps, one step per layer, and the apparent resistivity and phase curves of each site. They are written as PNG files and need no display.

Plot an inversion ​

After a 1D inversion, one call writes the standard plots of every site:

julia
run = Invert1D("data.dat", "InvCtrl.GN")
PlotInversion1D(run; true_model_path = "model.true")

Each site's plots/ folder then holds its model, its data fit and its convergence. For a VFSA run the model plot also shows the median and the 5–95 % range of the chains. true_model_path is only for synthetic tests; leave it out for field data.

Plot a model file ​

julia
PlotModel1D("model.rho"; output_path = "Model.png", maximum_depth = 5000)

maximum_depth (in metres) cuts the plot at that depth.

Build your own figure ​

The building blocks take the layer thicknesses and one or more models, so you can compare several models in one figure:

julia
plot_mt1d_model(h, [(ρ1, "GN", :black, :solid), (ρ2, "VFSA mean", :steelblue, :solid)];
                output_path = "Compare.png")

plot_mt1d_convergence draws the RMS history of GN or VFSA runs.
